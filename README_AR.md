# أوسكار المحاسبي — Telegram Bot v2

- تسجيل الدخول بنفس ملف `.mzauth` الخاص بالبرنامج.
- صلاحيات الأقسام تتبع صلاحيات الحساب.
- بيع نقدي وآجل من البوت مع تحديث المخزون والحسابات على نفس Turso.
- الأصناف/الأقسام/الفواتير/العملاء/الموردون/الحسابات/الورديات/السندات/المشتريات/المصروفات/المخزون/التقارير/البحث.
- أي عملية يكتبها البوت إلى Turso تظهر في البرنامج عبر مزامنة أوسكار الحالية.
- البرنامج يرسل إشعارات الفواتير إلى البوت عبر `/api/app/invoice`.

بعد النشر افتح `/setup` مرة واحدة لتحديث webhook وإنشاء جداول جلسات تيليجرام.
