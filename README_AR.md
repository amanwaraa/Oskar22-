# Oscar Telegram Bot v3.5

تم إصلاح عدم رد /start من الجذر:
- يدعم webhook على /webhook وعلى رابط Worker الرئيسي / للتوافق مع النسخ القديمة.
- فتح رابط Worker مرة واحدة يصلح webhook تلقائياً بدون الحاجة لكتابة /setup.
- /start ينتظر إرسال الرد قبل إنهاء طلب Cloudflare.
- إذا تعطلت D1 مؤقتاً، /start يظل يرسل أزرار تسجيل الدخول.
- /setup لم يعد يتوقف بسبب D1؛ يتم ربط Telegram أولاً ثم فحص D1.

بعد النشر افتح رابط Worker في المتصفح مرة واحدة. إذا ظهر Oscar Telegram Bot is connected فهذا يعني أن webhook تم ربطه.
# أوسكار المحاسبي — Telegram Bot v3.4

هذه النسخة تعالج توقف إرسال رسائل البوت بعد تحويل القوائم إلى أزرار أسفل خانة الكتابة.

## ما تم إصلاحه
- أزرار `/start` تظهر أسفل خانة الكتابة كـ Reply Keyboard بسيطة ومتوافقة.
- إزالة الحقول الإضافية التي قد تجعل Telegram يرفض لوحة الأزرار في بعض الحالات.
- إذا رفض Telegram لوحة الأزرار لأي سبب، يرسل البوت الرسالة نفسها بدون أن يترك المستخدم بلا رد.
- إضافة إعادة محاولة تلقائية لاتصال Telegram API عند أخطاء الشبكة المؤقتة.
- أي خطأ داخل معالجة التحديث لا يجعل البوت يصمت؛ يحاول إرسال رسالة خطأ مؤقت للمستخدم.
- `/start` لا يتوقف عن الرد إذا حصل خطأ مؤقت في قراءة/كتابة جلسة D1.
- تسجيل الدخول ما زال بملف `.mzauth` الأصلي فقط، مع التحقق من الشركة والحساب قبل إنشاء الجلسة.
- `/setup` يعيد تثبيت الـ Webhook من الصفر ويتحقق من هوية البوت قبل تثبيته.

## بعد الرفع إلى Cloudflare
1. نفّذ `npm install`.
2. نفّذ `npx wrangler deploy`.
3. افتح رابط الـ Worker وأضف `/setup` في النهاية **مرة واحدة بعد كل رفع لهذه النسخة**.
4. تأكد أن نتيجة `/setup` فيها `success: true` وأن `getMe` و `setWebhook` رجعا `ok: true`.
5. افتح `/status` وتأكد أن عنوان Webhook هو نفس رابط الـ Worker الحالي.
6. ارجع إلى Telegram وأرسل `/start`.

## تسجيل الدخول
اضغط `🔐 تسجيل الدخول` من الأزرار أسفل الشاشة ثم أرسل ملف أوسكار الأصلي بامتداد `.mzauth` كمستند. البوت يرسل أولاً حالة "جاري التحقق" ثم يفحص الملف والقاعدة والحساب قبل القبول.
