# أوسكار المحاسبي — Telegram Bot v3.0

نسخة معاد تصميمها للعمل مباشرة على نفس بيانات برنامج أوسكار في Turso وبنفس ملف الدخول `.mzauth`.

## تسجيل الدخول
- أرسل ملف `.mzauth` للمدير أو الموظف إلى البوت.
- القارئ مطابق لتنسيق `oscar-activation-runtime.js`.
- يتحقق من الشركة والحساب ومدة التفعيل ونسخة `authVersion`.
- إذا حصل عطل اتصال مؤقت أثناء التحقق، يقبل الملف مؤقتاً بعد التحقق المحلي ثم يعيد التحقق من قاعدة الشركة عند استخدامها. الأخطاء المنطقية مثل إيقاف الشركة أو انتهاء المدة لا يتم تجاوزها.
- صلاحيات أزرار البوت هي نفس صلاحيات الموظف داخل أوسكار.

## العمليات المتاحة
- لوحة التحكم والبحث الشامل.
- البيع النقدي والآجل وتحديث المخزون والحسابات والوردية.
- الفواتير وتفاصيلها والمرتجع الكامل.
- الأصناف والتصنيفات والبحث بالاسم/SKU/الباركود.
- العملاء وإضافة عميل مع رصيد افتتاحي.
- الموردون وإضافة مورد مع رصيد افتتاحي.
- المشتريات وإنشاء فاتورة شراء نقدية أو آجلة مع تحديث متوسط التكلفة والمخزون وFIFO.
- الحسابات والتحويل المالي بين الحسابات.
- الورديات: فتح وإغلاق وعرض المتوقع/الفعلي.
- سندات القبض والصرف.
- المصروفات.
- المخزون والنواقص والتحويل بين المخازن.
- الموظفون حسب الصلاحية.
- التقارير.

## وصول الفواتير تلقائياً للبوت
يوجد مساران مع منع التكرار:
1. `POST /api/app/invoice` لو أردت أن يدفع التطبيق الإشعار فوراً.
2. Cron كل دقيقة يراقب Turso تلقائياً للفواتير الجديدة والمشتريات ويرسلها لكل حساب Telegram مسجل حسب صلاحياته، بدون الحاجة لتعديل تطبيق أوسكار.

عند تسجيل الدخول يبدأ المؤشر من آخر فاتورة موجودة حتى لا يرسل الفواتير القديمة دفعة واحدة.

## النشر
```bash
npm install
npx wrangler deploy
```
ثم افتح:
`/setup`
مرة واحدة لتثبيت Webhook.

ملف `wrangler.jsonc` يحتوي Cron كل دقيقة.

## فحص الحالة
افتح `/status` لرؤية إصدار البوت وعدد الجلسات وحالة Telegram webhook.
