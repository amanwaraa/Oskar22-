# أوسكار المحاسبي — Telegram Bot v3.3

نسخة مرتبطة بنفس بيانات برنامج أوسكار في Turso، مع تسجيل دخول بملف `.mzauth` الأصلي فقط، وقوائم رئيسية ثابتة أسفل خانة الكتابة في تيليجرام.

## تسجيل الدخول الجديد
- اضغط `/start` وستظهر الأزرار **أسفل خانة الكتابة** وليس داخل الرسالة.
- اضغط **🔐 تسجيل الدخول**.
- من المشبك 📎 اختر **ملف** وأرسل نفس ملف أوسكار الذي ينتهي بـ `.mzauth`.
- لا يوجد تسجيل دخول بالنص المنسوخ في هذه النسخة.
- البوت لا يقبل الملف مباشرة: يفك تشفيره ثم يتحقق من الشركة وحالة التفعيل والحساب ونسخة `authVersion` من قاعدة أوسكار.
- عند خطأ اتصال مؤقت يعيد محاولة التحقق قبل إظهار الفشل، ولا يعتمد قبولاً محلياً مؤقتاً.
- بعد التحقق يجرب قراءة بيانات أوسكار وحالة المزامنة قبل إنشاء جلسة Telegram.

## تصميم الأزرار
- شاشة البداية: أزرار Reply Keyboard ثابتة أسفل الشاشة.
- بعد تسجيل الدخول: أهم أقسام أوسكار تظهر أيضاً كأزرار ثابتة أسفل خانة الكتابة حسب صلاحيات الحساب.
- الاختيارات المرتبطة بقائمة محددة، مثل اختيار صنف أو عميل، تبقى داخل الرسالة لأنها تخص العملية الحالية فقط.

## العمليات المتاحة
- لوحة التحكم والبحث الشامل.
- البيع النقدي والآجل وتحديث المخزون والحسابات والوردية.
- الفواتير وتفاصيلها والمرتجع الكامل.
- الأصناف والتصنيفات والبحث بالاسم/SKU/الباركود.
- العملاء والموردون والأرصدة الافتتاحية.
- المشتريات وإنشاء فاتورة شراء.
- الحسابات والتحويل المالي.
- الورديات وفتح/إغلاق الصندوق.
- السندات والمصروفات والمخزون والتحويلات والتقارير والموظفون حسب الصلاحيات.

## وصول الفواتير تلقائياً للبوت
- Cron كل دقيقة يراقب نفس Turso للفواتير والمشتريات الجديدة ويرسلها للحسابات المسجلة حسب الصلاحيات.
- يوجد أيضاً `POST /api/app/invoice` للدفع المباشر من التطبيق.
- يمنع تكرار نفس الفاتورة.

## النشر
```bash
npm install
npx wrangler deploy
```
بعد النشر افتح `/setup` مرة واحدة لتثبيت Webhook وأوامر البوت.

## فحص الحالة
افتح `/status` لرؤية إصدار البوت وعدد الجلسات وحالة Telegram webhook.
