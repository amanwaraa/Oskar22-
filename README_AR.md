# Oscar Telegram Store + Cashier SaaS v5.0

هذه النسخة تجمع متجر أوسكار P2P مع منتج **أوسكار كاشير بوت** ونظام شركات/اشتراكات.

## للمستخدم
- متجر البرامج الحالي + صور طرق الدفع وأزرار الاختيار.
- منتج أوسكار كاشير بوت داخل المتجر.
- تجربة مجانية 24 ساعة لمرة واحدة لكل حساب تيليجرام.
- إنشاء حساب باسم مستخدم وكلمة مرور، ثم الدخول بالحساب بدون ملفات.
- شراء اشتراك أثناء التجربة أو بعد انتهائها بنفس نظام P2P وإثبات الدفع.
- بمجرد اعتماد الأدمن للدفع يتم التفعيل أو التمديد تلقائياً وإشعار العميل.
- البيانات تبقى محفوظة بعد انتهاء الاشتراك للتجديد لاحقاً.

## الكاشير داخل تيليجرام
- الأصناف والمخزون.
- فاتورة بيع نقدي / جزئي / آجل.
- العملاء وأرصدة افتتاحية.
- الموردون وأرصدة افتتاحية.
- المشتريات وتحديث المخزون ومتوسط التكلفة.
- المصروفات.
- الصندوق.
- تقرير يومي.

## لوحة الأدمن
- إدارة برامج المتجر وطرق الدفع والصور.
- إدارة خطط الاشتراك: الاسم + عدد الأيام + السعر + العملة.
- مراجعة طلبات الاشتراك وقبول/رفض إثبات الدفع.
- عرض حسابات/شركات الكاشير.
- إنشاء شركة وحساب يدوياً من داخل البوت.
- إضافة أي عدد أيام للحساب يدوياً.

## القاعدة الأم Turso
النسخة مربوطة بسجل الشركات في القاعدة الأم:
`libsql://mezan-homworkhhh76-rgb.aws-ap-northeast-1.turso.io`

يتم إنشاء جدول `bot_saas_companies` تلقائياً وتحديثه عند إنشاء الحساب أو تمديد الاشتراك.
تم تضمين بيانات الاتصال المقدمة لهذه النسخة لتعمل مباشرة. للأمان عند النشر العام يفضل نقل التوكن إلى Cloudflare Secret باسم `MASTER_TURSO_TOKEN` وتدويره عند الحاجة.

## التشغيل
1. ارفع المشروع على Cloudflare Workers.
2. تأكد من وجود D1 binding باسم `DB` كما في `wrangler.jsonc`.
3. افتح رابط الـWorker مع `/setup` مرة واحدة.
4. افتح البوت وأرسل `/start`.
5. حساب الإدارة هو `@PUPGG_PAY`، ويجب أن يرسل `/start` مرة واحدة حتى يثبت `chat_id` للإدارة.
6. من لوحة الإدارة افتح **خطط الاشتراك** وعدّل الأسعار؛ الخطتان الافتراضيتان شهر/سنة تبدأان بسعر 0 حتى تحددهما أنت أو تضيف خططاً جديدة.

## الأمان
- كلمات المرور محفوظة PBKDF2-SHA256 + Salt مستقل وليست كنص عادي.
- البوت يحاول حذف رسالة كلمة المرور بعد قراءتها.
- كل بيانات الكاشير معزولة حسب `account_id`.
