# Oscar Telegram Bot v3.6

هذه النسخة تعالج تسجيل الدخول بملف `.mzauth` وتضيف لوحة مشرف مرتبطة بالقاعدة الأم لنظام أوسكار.

## تسجيل الدخول
- تسجيل الدخول يتم بإرسال ملف `.mzauth` نفسه كمستند، وليس نسخ النص داخله.
- الملف ينزل من Telegram كبايتات مباشرة.
- القارئ يستخدم نفس PBKDF2/AES-GCM الموجود في `oscar-activation-runtime.js`.
- تمت إضافة قراءة مرنة لـ UTF-8 / BOM / UTF-16 / Base64 URL-safe مع بقاء التحقق المشفر نفسه.
- بعد فك الملف يتم التحقق من الشركة، حالة التفعيل، الحساب ونسخة `authVersion` ثم اختبار قاعدة الشركة فعلياً قبل إنشاء الجلسة.

## لوحة المشرف والقاعدة الأم
من `/start` يوجد زر `🛡 المشرف` أسفل خانة الكتابة.

في أول تشغيل فقط، إذا لم يوجد أي مشرف مسجل، يطلب البوت:
1. رابط Turso للقاعدة الأم.
2. توكن الكتابة للقاعدة الأم.
3. يختبر الاتصال ثم يسجل نفس Telegram Chat كأول مشرف.

بعد ذلك تظهر لوحة المشرف وبها:
- `🗄 قاعدة الأم`
- `🧱 قواعد الشركات`
- `➕ قاعدة`
- `🏢 الشركات`
- `➕ شركة`

### إضافة قاعدة شركة
يطلب البوت:
- اسم القاعدة.
- رابط Turso.
- توكن الكتابة.
- توكن القراءة فقط للعملاء.

ويتحقق من التوكنين ثم يخزن بيانات القاعدة في نفس مسار إدارة أوسكار:
`oscar/admin/databases/...`

الخزنة `vault` متوافقة مع AES-GCM المستخدم في لوحة `admin.html` الأصلية.

### الشركات
- يعرض الشركات المسجلة في القاعدة الأم.
- يمكن إنشاء شركة جديدة واختيار القاعدة التابعة لها.
- يتم إنشاء مفتاح شركة ومدير وتاريخ صلاحية.
- يتم نشر `access/company` إلى قاعدة الشركة.
- بعد إنشاء الشركة يرسل البوت ملف مدير `.mzauth` متوافقاً مع أوسكار.
- من قائمة الشركات يمكن تنزيل ملف المدير أو إيقاف/تفعيل الشركة.

## النشر
بعد رفع النسخة:
1. `npm install`
2. `npx wrangler deploy`
3. افتح رابط Worker مرة واحدة أو `/setup` لتحديث Webhook.
4. أرسل `/start`.

> يفضل إضافة Secret باسم `MASTER_SECRET` في Cloudflare لحماية توكن القاعدة الأم المخزن في D1. إذا لم تضفه تستخدم النسخة مفتاح البوت كحماية توافقية.
