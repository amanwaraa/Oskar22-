# Oscar P2P Store Bot v4.0

بوت متجر تيليجرام لبيع برامج أوسكار بنظام دفع يدوي P2P وإثبات دفع.

## تجربة المستخدم
- `/start` يفتح واجهة متجر بأزرار ثابتة أسفل خانة الكتابة.
- `🛍 تصفح البرامج`: يعرض صورة كل برنامج + الوصف + السعر + زر `شراء الآن`.
- يختار المستخدم طريقة الدفع.
- تظهر صورة وبيانات طريقة الدفع وتعليمات التحويل.
- بعد الدفع يضغط `✅ دفعت — إرسال الإثبات` ويرسل صورة الإثبات.
- ينشأ طلب برقم P2P ويحفظ في D1 ويرسل فوراً لصاحب البوت للمراجعة.
- بعد اعتماد الدفع يصل للمستخدم تأكيد + رسالة الاستلام الخاصة بالبرنامج.
- `📦 طلباتي` يعرض حالة آخر الطلبات.

## لوحة الإدارة
حساب الإدارة الافتراضي هو `@PUPGG_PAY`.

> مهم: يجب أن يفتح صاحب الحساب `@PUPGG_PAY` البوت ويرسل `/start` مرة واحدة حتى يحفظ البوت رقم Telegram chat_id الخاص به، لأن بوتات تيليجرام لا تستطيع بدء محادثة خاصة مع مستخدم بالـ username فقط.

بعدها تظهر له لوحة إدارة ثابتة أسفل خانة الكتابة:
- `📦 البرامج`: إضافة برنامج، الصورة، الوصف، السعر، العملة، رسالة ما بعد اعتماد الدفع، تعديل/إخفاء/حذف.
- `💳 طرق الدفع`: إضافة أو تعديل اسم الطريقة وبيانات التحويل والصورة، إخفاء/إظهار/حذف.
- `🧾 الطلبات`: مراجعة الطلبات والإثباتات واعتماد أو رفض الدفع.
- `⚙️ إعدادات المتجر`: اسم المتجر، الترحيب، حساب الدعم، صورة واجهة المتجر.

## رفع النسخة
1. ارفع الملفات إلى مشروع Cloudflare Worker الحالي.
2. تأكد أن Binding قاعدة D1 اسمه `DB`.
3. يفضل وضع توكن البوت في Secret باسم `BOT_TOKEN`:
   `npx wrangler secret put BOT_TOKEN`
4. نفذ `npx wrangler deploy`.
5. افتح رابط الـWorker أو `/setup` مرة واحدة لإعادة ضبط الـWebhook.
6. من حساب `@PUPGG_PAY` افتح البوت وأرسل `/start` مرة واحدة.

## ملاحظات تصميم
- الأزرار الرئيسية Reply Keyboard ثابتة أسفل خانة الكتابة.
- أزرار المنتجات والدفع والمراجعة Inline Keyboard أسفل الرسائل والصور.
- الصور لا تحتاج استضافة خارجية: البوت يحفظ Telegram `file_id` ويعيد استخدامها مباشرة.
- الدفع يدوي P2P: البوت لا يسحب أموالاً ولا يخزن بطاقات؛ فقط يعرض بيانات الدفع ويستقبل إثبات التحويل للمراجعة.
